Accelerometer

A sensor that measures acceleration. The report proposes using phone acceleration and vibration data alongside GPS and image detections to investigate pavement defects.

Report §5.2 ↗
Alligator cracking

An interconnected pattern of cracks resembling alligator skin. The report describes it as fatigue distress associated with repeated traffic loading.

Report §2.2.1 ↗
Artificial intelligence (AI)

Computer systems that perform tasks such as recognising images and analysing information. Here, AI describes the overall pavement defect detection system.

Report §2.4.3 ↗
Basecourse

The principal structural layer below the wearing surface. It distributes traffic loads to the subbase and subgrade.

Report §2.1 ↗
Bleeding

Asphalt binder rising to the pavement surface, producing a shiny surface that can reduce skid resistance.

Report §2.2.2 ↗
Block cracking

A rectangular pattern of cracks associated with binder shrinkage, ageing and temperature changes.

Report §2.2.1 ↗
Bounding box

A rectangle marking the location of a labelled or predicted defect in an image. The class label describes the type of defect inside it.

Report §2.4.1 ↗
Confidence score

The score attached to an individual model prediction. The gallery retains the saved scores and uses a 0.40 detection threshold. A confidence score is not measured model accuracy.

Report §3.6 and gallery prediction record ↗
Convolutional neural network (CNN)

A deep learning model suited to spatial patterns in images, such as edges, textures and pavement defects.

Report §2.4.4 ↗
Corrugation

Repeated small ridges and troughs in the road surface, commonly associated with unstable surface layers and vehicle movement.

Report §2.2.2 ↗
Crack sealing

A maintenance treatment that seals cracks to limit water entering the pavement structure and reduce further deterioration.

Report §2.3.1 ↗
Dataset

A collection of images and their labels used to train or evaluate the model. This project uses RDD2022 and locally collected New Zealand imagery.

Report §3.1 ↗
Deep learning

Machine learning that uses multiple layers to learn visual features from image pixels, rather than relying on manually specified visual rules.

Report §2.4.4 ↗
Edge cracking

Cracking and deterioration along the edge of a pavement. The report links it to inadequate lateral support, drainage problems or heavy traffic.

Report §2.2.1 ↗
Epoch

One complete pass through the training dataset while the model learns. Training runs in the report are compared across epochs.

Report §3.3 ↗
Generalisation

How well a trained model performs on new, unseen road imagery. Strong results on a small local validation set do not establish reliable performance across other roads and conditions.

Report §4.3 ↗
Global positioning system (GPS)

Location information used to associate road images and detected defects with geographic positions on the interactive map.

Report §3.6 ↗
Graphics processing unit (GPU)

Hardware used to accelerate model training. The project moved larger training runs from local hardware to GPUs available through Google Colab.

Report §5.1 ↗
Gyroscope

A sensor that measures rotational movement. The report proposes combining a phone’s gyroscope and accelerometer readings with GPS and YOLO results to assess more pavement defects.

Report §5.2 ↗
Labelled data

Images paired with the expected defect class and its bounding box. These examples provide the supervision used to train the detector.

Report §2.4.1 ↗
Large language model (LLM)

A proposed future stage that could examine images after detection to help assess visible defect characteristics. The report proposes this work; the website does not provide automated severity assessment.

Report §5.2 ↗
Longitudinal cracking

Cracks running approximately parallel to the road centreline. The model label used in the gallery is long_crack.

Report §2.2.1 ↗
Machine learning (ML)

A subset of AI in which a model learns patterns from data. In this project it refers to the supervised detector trained on labelled road images.

Report §2.4.3 ↗
Mean average precision at 0.5 (mAP50)

The report’s main detection metric, combining classification and bounding-box localisation at an overlap threshold of 0.5. It is reported from 0 to 1 and must be interpreted with the validation dataset.

Report §2.5 ↗
Overfitting

Learning patterns specific to a small training or validation dataset without performing reliably on new imagery. The report cautions that its high local validation scores may reflect overfitting.

Report §4.3 ↗
Pavement Distress Index (PDI)

In this project, the number of detected defects assigned to a 50 m road section. Each defect contributes one, regardless of class; a higher value indicates a greater concentration of detections.

Report §3.7 ↗
Pothole

A bowl-shaped cavity in the pavement surface. Moisture and repeated traffic loading can progressively weaken and remove pavement material.

Report §2.2.3 ↗
Pothole patching

A reactive repair that replaces or fills damaged surface material. A patch may have limited durability if the underlying moisture problem remains.

Report §2.3.2 ↗
Precision

The proportion of reported defect detections that are correct. It describes the reliability of detections, while recall describes how many real defects were found.

Report §2.5 ↗
Ravelling

Progressive loss of aggregate particles from the pavement surface as the material separates from the binder.

Report §2.2.3 ↗
Recall

The proportion of real, labelled defects that the model detects. Missing visible defects reduces recall.

Report §2.5 ↗
Reinforcement learning

Learning by interacting with an environment and receiving reward-based feedback. It is discussed in the report but is not used for this supervised image detection task.

Report §2.4.2 ↗
Road Damage Dataset 2022 (RDD2022)

The international labelled road imagery used to establish the project’s baseline detector before introducing New Zealand imagery.

Report §3.1 ↗
Rutting

Permanent deformation along wheel paths under repeated traffic loading. Ruts can retain water and reduce ride quality.

Report §2.2.2 ↗
Shoving

Localised wrinkling or movement of pavement, often near braking locations such as intersections.

Report §2.2.2 ↗
Stripping

Loss of the bond between asphalt binder and aggregate associated with moisture entering the pavement.

Report §2.2.3 ↗
Subbase

The layer between the subgrade and basecourse. It helps distribute loads, supports drainage and protects the subgrade.

Report §2.1 ↗
Subgrade

The prepared natural soil foundation beneath the pavement layers.

Report §2.1 ↗
Supervised learning

Training with examples that include both the input image and the expected output. For this project, the output includes the defect class and bounding box.

Report §2.4.1 ↗
Surface disintegration

Breakdown and loss of material from the wearing surface, including potholes, ravelling and stripping.

Report §2.2.3 ↗
Surface treatment

Maintenance of a deteriorating wearing surface to restore texture or waterproofing. The report discusses chip treatments, resealing and more extensive replacement.

Report §2.3.3 ↗
Training and validation split

The division between data used to fit the model and data used to evaluate it. The preparation method described in the report uses an 80% training and 20% validation split.

Report §3.2 ↗
Transverse cracking

Cracks running approximately perpendicular to the road centreline. The detector’s lateral_crack label is shown as transverse cracking in the gallery.

Report §2.2.1 ↗
Unsupervised learning

Finding patterns or groups in data without predefined labels. It is discussed as an alternative, but this project uses supervised learning.

Report §2.4.2 ↗
Wearing surface

The uppermost pavement layer exposed to traffic and weather. It provides surface texture, skid resistance and protection for the layers below.

Report §2.1 ↗
You Only Look Once (YOLO)

The object detection model family used to locate and classify pavement defects in images. The report compares several model sizes and training configurations.
