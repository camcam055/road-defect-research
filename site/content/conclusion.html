6.0 Conclusion

This preliminary report has shown that there has been significant progress towards developing an AI-based surface defect detection system for New Zealand pavement conditions. A baseline model was trained using the RDD2022 dataset which included defects in an international setting. The labels for this dataset where then converted into YOLO text format for training and used to train multiple YOLO models. Then New Zealand specific road defect footage was then collected and used to train the model on New Zealand pavement conditions.

The preliminary results showed that the model can learn pavement defects from the international dataset. Testing between the small, large and extra-large YOLO models showed that increasing the model size led improved performance up to a point. The larger model achieved the best balance between performance and accuracy, over the small and extra-large model. However, when testing the extra-large model, the model did not improve compared to the large model. This may suggest that increasing the model while keeping the image quality and the dataset the same may not mean that the model will improve. So, the final model that is selected should be judged on a large New Zealand specific dataset and real-world performance rather than performance using training results.

Overall, the project is progressing towards its aim of developing a low-cost AI defect detection system. The next stage of the project should focus on collecting high-quality data and a larger and more diverse New Zealand-specific dataset, improving validation on unseen footage, developing a PDI calculation method and app development. This will allow the final system to be able to detect defects consistently across different environmental conditions.
